# Suggested Gamified Mission Path

## Tier 1 - Recon
- Discover hosts in target subnet
- Identify open web service and SSH service
- Submit flags for host discovery and service mapping

## Tier 2 - Web Exploitation
- Access DVWA on target host
- Solve SQL injection challenge
- Solve command injection challenge

## Tier 3 - Credential and Lateral Movement
- Crack a provided password hash
- Reuse credentials against second target
- Capture lateral movement proof flag

## Tier 4 - Defense and Detection
- Capture packet trace for exploit traffic
- Write a detection rule for malicious pattern
- Document mitigation steps and hardening actions
