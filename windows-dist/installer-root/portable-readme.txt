Cyber Security Operations Platform

Portable deployment package

Requirements:
- Node.js 20+ must be installed on the target computer.
- Run install.bat to install dependencies, create shortcuts, and launch the application.

Launch options after install:
- Desktop shortcut: Cyber Security Operations Platform
- Start Menu shortcut: Cyber Security Operations Platform
- Manual launcher: launch-cyber-ops.cmd

Default sign-in:
- Username: admin
- Password: SecurePass2026!

Application URL:
- http://localhost:3000
