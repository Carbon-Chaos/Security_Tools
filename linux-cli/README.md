# Cyber Security CLI

A separate Linux command-line toolkit for security operations tasks.

## Commands
- `cyber-sec overview`
- `cyber-sec assets`
- `cyber-sec alerts`
- `cyber-sec incidents`
- `cyber-sec scan <target>`
- `cyber-sec decrypt <base64-ciphertext> [key]`

## Install
```bash
cd linux-cli
npm install
npm link
```
